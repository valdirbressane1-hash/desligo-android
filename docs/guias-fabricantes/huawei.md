# Guia de Configuração — Huawei / EMUI / HarmonyOS

## ⚠️ Atenção
Huawei é o fabricante mais agressivo com apps em background. Siga todos os passos.

## Passos

### 1. Inicialização de Apps
1. Abra **Configurações** → **Bateria** → **Inicialização de apps**
2. Encontre **Desligo**
3. Ative **Gerenciar manualmente**
4. Ative todas as opções:
   - ✅ Iniciar automaticamente
   - ✅ Execução em segundo plano
   - ✅ Iniciar automaticamente

### 2. Sem Restrições de Bateria
1. Vá para **Configurações** → **Apps** → **Apps** → **Desligo** → **Bateria**
2. Selecione **Sem restrições**

### 3. Proteger no Multitasking
- No multitasking, deslize Desligo para baixo
- Aparecerá um cadeado 🔒 — toque para travar

### 4. Proteção de Bateria (se necessário)
- Em Configurações avançadas de bateria, desative a "Proteção de bateria" para o Desligo

## Notas
- EMUI 12+ e HarmonyOS são ainda mais agressivos
- Se o app parar após reiniciar o celular, repita o passo 1
