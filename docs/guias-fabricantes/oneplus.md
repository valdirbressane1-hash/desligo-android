# Guia de Configuração — OnePlus / OxygenOS

## Passos

### 1. Não Otimizar Bateria
1. Abra **Configurações** → **Bateria** → **Otimização de bateria**
2. Encontre **Desligo**
3. Selecione **Não otimizar**

### 2. Executar em Background
1. Vá para **Configurações** → **Apps** → **Desligo**
2. Ative **Executar em background**

### 3. Fixar no Multitasking
- No multitasking, deslize Desligo para baixo para travar o app

## Notas
- OxygenOS é relativamente amigável com apps em background
- Pode ter problemas após atualizações maiores do sistema
- OnePlus 9+ com ColorOS (baseado no Android 12+) pode ter comportamento diferente
