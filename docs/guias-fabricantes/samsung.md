# Guia de Configuração — Samsung / One UI

## Passos

### 1. Bateria Sem Restrições
1. Abra **Configurações** → **Apps** → **Desligo**
2. Toque em **Bateria**
3. Selecione **Sem restrições**

### 2. Permitir em Background
1. Na mesma tela de Bateria
2. Verifique se **Permitir em background** está ativo

### 3. Otimização de Bateria
1. Vá para **Configurações** → **Manutenção do dispositivo** → **Bateria**
2. Desative **Otimização automática** ou adicione Desligo às exceções

## Notas
- Samsung One UI geralmente é menos agressivo que MIUI
- Pode ter problemas após atualizações do sistema
- Se usar "Modo de economia de bateria", verificar se Desligo está na lista de apps permitidos
