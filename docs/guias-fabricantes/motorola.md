# Guia de Configuração — Motorola

## Passos

### 1. Não Otimizar Bateria
1. Abra **Configurações** → **Bateria** → **Otimização de bateria**
2. Encontre **Desligo**
3. Selecione **Não otimizar**

### 2. Sem Restrições
1. Vá para **Configurações** → **Apps** → **Desligo** → **Bateria**
2. Selecione **Sem restrições**

### 3. Manter em Background
- Mantenha Desligo aberto no multitasking

## Notas
- Motorola geralmente é menos restritivo
- A Moto Actions pode interferir em alguns casos
- Android One (Motorola One series) é mais permissivo
